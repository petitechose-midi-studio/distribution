## Additional
This beta brings the completed Core sequencer, macro history, persistence and filesystem refactor into one synchronized distribution, with updated Bridge, Loader, Core host tools and Bitwig integration.

Use it together with **MS Manager v0.1.4-beta.4**. Install the new Manager, install/select distribution **v0.1.0-beta.6** for the device, then flash the chosen Core or Bitwig firmware. Core filesystem management uses the new RPC v6 contract; mixed old/new Manager, Bridge and Core versions are not a supported filesystem-management combination. Firmware installation remains the route to bring the device up to date.

Core consolidates musical state and undo/redo ownership, reduces redundant copies, removes legacy filesystem RPC paths and integrates the qualified USB MIDI and SDIO driver corrections. Bitwig uses the same pinned HAL adapters and device-support dependency.

The release is assembled from signed candidates with immutable source and tooling pins. Firmware memory checks retain their strict RAM and ITCM limits. Core reports an existing advisory Flash code overrun of 22720 bytes; no limit was relaxed for publication.
